# دعوتي برو V12

## Studio Editor
- محتوى الدعوة في لوحة واحدة
- لوحات ألوان جاهزة مع تخصيص HEX
- خط، استدارة، حجم العناوين، وطبقة الصورة
- إظهار/إخفاء الأقسام
- سحب وإفلات الأقسام + أسهم الترتيب
- معاينة مباشرة بإطار هاتف
- حفظ ونشر عبر API

## ملاحظة
التخزين الحالي ملفي/محلي ومناسب للتطوير. قبل الإطلاق التجاري يجب نقل البيانات إلى PostgreSQL أو خدمة قاعدة بيانات، وإضافة تخزين ملفات سحابي، صلاحيات إنتاجية، CSRF/rate limiting، ومراجعة أمنية.
